
# Vanya Sales Autopilot

A lightweight web MVP for public market research, opportunity
ranking, and digital product planning.

## Run locally

Install dependencies:

    pip install -r requirements.txt

Start the application:

    streamlit run app.py

## Deploy

1. Push app.py, requirements.txt, and README.md to GitHub.
2. Open https://share.streamlit.io/
3. Connect your GitHub account if needed.
4. Select your repository and the main branch.
5. Set the main file path to app.py.
6. Deploy the application.

Keep repository visibility and app-sharing settings in mind.
Do not commit API keys, passwords, or other secrets.

## Limitations

- Uses public web sources and may encounter access restrictions.
- Scores are heuristic rankings, not validated demand estimates.
- Search results do not establish willingness to pay.
- No automatic publishing, purchases, or transactions.
- Generated product material requires human review.
